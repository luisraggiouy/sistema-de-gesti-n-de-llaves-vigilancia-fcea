=====================================================
  PENDRIVE RECUPERADOR - SISTEMA DE LLAVES FCEA
=====================================================

ATENCION: Si al arrancar Windows aparece una ventana negra
diciendo "chrome.exe no encontrado" CIERRELA y siga este
instructivo. Mi script eliminara esa ventana de aparecer
para siempre.


-----------------------------------------------------
PASO 1 (PRIMERO INTENTE ESTE):
-----------------------------------------------------
Conecte este pendrive y haga DOBLE CLIC en:

   >>>  REPARAR-Y-INICIAR-SISTEMA.bat  <<<

Acepte el aviso de Windows (boton "Si" del UAC).

Vera una ventana azul oscuro con titulo:
"REPARAR Y INICIAR SISTEMA DE LLAVES FCEA"

Hace 7 pasos automaticamente:
  [0/7] LIMPIA tareas programadas viejas y archivos rotos
        que abren la ventana del error de Chrome al arrancar
  [1/7] Verifica Node.js (lo instala si falta)
  [2/7] Verifica que el sistema este copiado en C:\
  [3/7] Verifica/restaura la base de datos
  [4/7] Instala dependencias (node_modules)
  [5/7] Inicia PocketBase (base de datos)
  [6/7] Inicia el servidor Frontend (puerto 8080)
  [7/7] Abre el navegador en Monitor y Terminal

Tiempo total:
  - Si todo esta instalado: 30 seg a 2 min
  - Primera vez: 5 a 10 min (instala node_modules)

DESPUES DE QUE TERMINE:
  - REINICIE LA PC
  - Al arrancar, la ventana del error de Chrome ya NO debe aparecer.
  - Si aparece, ejecute este script otra vez (limpia mas
    fuerte) o pase al PASO 2.


-----------------------------------------------------
PASO 2 (SOLO SI EL PASO 1 NO LO RESUELVE):
-----------------------------------------------------
Doble clic en:

   >>>  REINSTALAR-COMPLETO.bat  <<<

Borra TODO y reinstala desde cero.
Antes hace respaldo de los datos en el Escritorio
(carpeta RESPALDO_LLAVES_FCEA_xxxxxx).

Le pedira escribir "SI" para confirmar.
Tiempo: 10 a 15 minutos.


-----------------------------------------------------
LA VENTANA NO SE CIERRA SOLA - LEA LOS COLORES:
-----------------------------------------------------
  Verde  [OK]    = paso correcto
  Amarillo [!]   = aviso (no es error)
  Rojo  [ERROR]  = problema real

Despues de cada ejecucion queda en este pendrive:
  ultimo_log_reparacion.txt
  ultimo_log_reinstalacion.txt

Si algo falla, ENVIE ESE ARCHIVO al soporte.


-----------------------------------------------------
CONTENIDO DEL PENDRIVE:
-----------------------------------------------------
  REPARAR-Y-INICIAR-SISTEMA.bat   <- USAR PRIMERO
  REINSTALAR-COMPLETO.bat         <- Solo emergencia
  LEEME-PRIMERO.txt               <- Este archivo

  sistema/         (codigo del sistema, sin .bat)
  respaldos_db/    (base de datos para restaurar)
  instaladores/    (Node.js si falta)
  docs/            (documentacion)
