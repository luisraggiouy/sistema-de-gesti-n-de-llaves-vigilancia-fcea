1. POCKETBASE - ADMINISTRADOR DE BASE DE DATOS
----------------------------------------------------------------
  Descripción : Acceso al panel de administración de PocketBase
                (base de datos del sistema). Permite ver/editar
                todos los registros directamente.
  URL         : http://localhost:8090/_/
  Email       : vigilancia@llaves.local
  Contraseña  : vigilanciamvp2026
  Uso         : Solo para mantenimiento técnico y scripts de
                administración del sistema.

----------------------------------------------------------------
2. MONITOR DE VIGILANCIA - CONTRASEÑA ADMINISTRADOR
----------------------------------------------------------------
  Descripción : Contraseña para acceder al panel de
                administración dentro del Monitor de Vigilancia
                (gestión de llaves, vigilantes, configuración,
                exportación de datos, etc.)
  URL         : http://localhost:8080/monitor → botón "Admin"
  Contraseña  : (configurada en la colección admin_config
                 de PocketBase, clave: admin_password)
  Contraseña por defecto: admin2026
  Uso         : Administrador del sistema en el día a día.

----------------------------------------------------------------
3. MONITOR DE VIGILANCIA - CONTRASEÑA CUSTODIO
----------------------------------------------------------------
  Descripción : Contraseña de acceso reducido para el custodio.
                Permite ver estadísticas y exportar reportes
                pero no modificar configuración del sistema.
  URL         : http://localhost:8080/monitor → botón "Admin"
                → opción "Ingresar como Custodio"
  Contraseña por defecto: custodio2026
  Uso         : Personal de custodia con acceso limitado.

----------------------------------------------------------------
NOTAS IMPORTANTES
----------------------------------------------------------------
  - Las contraseñas del Monitor (admin y custodio) se pueden
    cambiar desde el propio panel de administración del Monitor.
  - La contraseña de PocketBase solo se puede cambiar desde
    el panel de administración de PocketBase (/_/).
  - Si se olvida la contraseña de PocketBase, se debe
    restaurar desde un backup o reinstalar el sistema.
